Tester build

Maria

A desktop AI companion that watches your Minecraft game, spots mobs, ores and hazards, and talks to you by voice and chat.

Download

Download the tester build Windows only. About 56 MB. On the release page, pick the file named maria-tester-…zip.

What you need

  • Windows 10 or 11, and Minecraft.
  • Python 3.12 or newer. Tick “Add python.exe to PATH” when you install it.
  • Ollama with the llava:7b model (about 4.7 GB). The setup script can download it for you.
  • A Roboflow API key. I will send it to you privately, so please don’t share it.

Set up in 4 steps

  1. Unzip the download anywhere.
  2. Double-click setup.bat and follow the prompts. It installs everything and asks for your key.
  3. Make sure Ollama is running (look for its icon in the system tray).
  4. Double-click run.bat, then switch to Minecraft within 5 seconds.

While it runs

  • Ctrl+Alt+G opens the chat window. Ask “can you see my house?” to try the vision step.
  • Ctrl+Alt+S opens the status window with live settings: voice volume and speed, mute, and detection thresholds. Changes apply right away.

Privacy: please read

  • Maria captures your whole primary screen every few seconds.
  • Those frames are sent to Roboflow, a hosted service, for detection.
  • The last 50 captures are also saved on your PC in the debug_captures folder.
  • Close anything private before you start, and stop Maria when you’re done.

What to try and send back

  • Does she notice mobs, ores and lava? Is anything wrong or missing?
  • Do the settings in the status window do what they say?
  • How slow is it on your PC? About 5 seconds per comment is normal for now.
  • Send me what broke (copy any error text from the black window), your PC (CPU, GPU, RAM), and the newest file in the logs folder, if there is one. That file lists what Maria saw and said, plus any messages you typed to her, so read it first.
